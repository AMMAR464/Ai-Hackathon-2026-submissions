# AI Hackathon 2026 — Submissions

Welcome to the official submission repository.

## How to Submit Your Project

Each team must create its own folder inside the `teams` folder.

### Folder naming format

Use:

TEAM-ID_TEAM-NAME

Example:

TEAM-001_AI-Wizards

### Your folder should contain

- `README.md` — project information
- All source code
- Required assets/files
- Setup and running instructions

### README.md format

# Project Name

## Team ID
TEAM-001

## Team Name
AI-Wizards

## Team Members
- Member 1
- Member 2
- Member 3

## Project Description
Describe your project here.

## Technologies Used
- Python
- AI/ML
- C++
- etc.

## How to Run
Explain the steps required to run your project.

## Demo
Add your demo link here.
